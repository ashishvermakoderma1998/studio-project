## 📦 How to Upload to GitHub

1. Open your terminal in the project folder:
```bash
git init
git add .
git commit -m "feat: Ashish Wedding Film Studio production release"
```

2. Create a new repository on [GitHub](https://github.com/new).

3. Link and push your repository:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

## ⚡ How to Deploy on Vercel (Live in 1 Click)

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New Project** and select your uploaded GitHub repository.
3. Vercel will automatically detect the settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.
5. Your website will be live with full routing and booking capability!
